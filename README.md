# BlockyCubes
A voxel game heavily inspired by Minecraft

# Setup:
Using Gradle so you can run it easily.

# Features:
-Lighing
-Saving/Loading world
-Tree and vegetation generation
-Terrain and Cave generation
-Multiple Block types (including light source)
-Particle when breaking
-Fullscreen feature

# Debuggings:
F - Fly
X - Xray

# Bugs:
-torch positioning
-pigs AI and physics
